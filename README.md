# Deep-Learning-Assignments

This repository contains two Deep Learning projects implemented using TensorFlow and Keras.

## Project 1: Dogs vs Cats Classification

* Binary Image Classification
* Convolutional Neural Network (CNN)
* TensorFlow/Keras
* Dataset: Dogs and Cats Image Dataset

## Project 2: Transfer Learning using VGG16 and ResNet50

* Multi-Class Image Classification
* Transfer Learning
* TensorFlow/Keras
* Pre-trained Models: VGG16 and ResNet50
* Dataset: Intel Image Classification Dataset

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-Learn
